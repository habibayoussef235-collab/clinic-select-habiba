# Clinic Select - نظام إدارة العيادة

نظام متكامل لإدارة العيادات الطبية مصمم للعالم العربي، يدعم ستة أطباء مع إدارة المرضى والمواعيد والتقويم والسجلات الطبية والتقارير.

## 🚀 التشغيل السريع

```bash
cd clinic-select
venv\Scripts\python app.py
```

ثم افتح: `http://127.0.0.1:5000`

## 🔑 بيانات الدخول التجريبية

| الدور | اسم المستخدم | كلمة المرور |
|-------|-------------|------------|
| مدير / طبيب | Habiba | admin123 |
| موظف استقبال | Reem | user123 |

يوجد زر "دخول سريع" في صفحة تسجيل الدخول لتجربة كل دور بسهولة.

## ✅ المميزات

- 🔐 نظام تسجيل دخول مع صلاحيات (Admin / Receptionist)
- 🏥 إدارة الأطباء والأقسام ومواعيد العمل
- 👥 إدارة المرضى والسجلات الطبية (فصيلة دم، حساسية، تاريخ مرضي)
- 📅 حجز المواعيد مع عرض الأوقات المتاحة لكل طبيب
- 📆 تقويم شهري لمواعيد المرضى
- 📝 تسجيل الجلسات والمتابعات والكشوفات
- 📋 الملف الطبي الكامل لكل مريض (عرض وطباعة)
- 📊 طباعة تقرير مواعيد اليوم
- 📄 تصدير بيانات المرضى والمواعيد إلى CSV
- 🖨️ طباعة روشتة العلاج لكل زيارة
- 🎨 واجهة عربية بتصميم RTL وخط Cairo
- 🎨 ألوان طبية مناسبة
